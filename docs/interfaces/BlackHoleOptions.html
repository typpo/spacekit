Optional backgroundTexture

backgroundTexture: Texture
  • Defined in BlackHole.ts:66

Optional caller-owned equirectangular sky, with north at +Z and longitude zero at +X (center of texture). Replaces the background with a lensed sky. Use on only one black hole per scene. Enable lensScene to also lens objects.

Optional diskNormal

diskNormal: Coordinate3d
  • Defined in BlackHole.ts:47

Optional exposure

exposure: number

Display exposure, positive. Default 1.

Optional lensScene

lensScene: boolean
  • Defined in BlackHole.ts:60

Lens the camera image, including meshes, sprites, lines and particles. Default false. Screen-space approximation for perspective cameras. Requires WEBGL_depth_texture; uses captured finite source distances. Enable on at most one black hole per simulation.
