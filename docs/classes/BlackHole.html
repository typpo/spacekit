Class BlackHole

A stationary Schwarzschild black hole, with GPU null-geodesic ray tracing. Models light around an isolated non-spinning, uncharged mass; it does not change Spacekit's Kepler orbits or simulate accretion hydrodynamics. Requires WebGL EXT_frag_depth and highp fragment precision.
