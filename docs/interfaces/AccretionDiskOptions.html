Optional aspectRatio

aspectRatio: number
  • Defined in BlackHole.ts:26

Optional innerRadius

innerRadius: number
  • Defined in BlackHole.ts:18

In Schwarzschild radii, at least 3 (the ISCO). Default 3.

Optional opticalDepth

opticalDepth: number
  • Defined in BlackHole.ts:24

Vertical optical depth of the emitting layer. Default 2.

Optional outerRadius

outerRadius: number
  • Defined in BlackHole.ts:20

In Schwarzschild radii, greater than innerRadius. Default 12.

Optional rotationSpeed

rotationSpeed: number
  • Defined in BlackHole.ts:30

Disk animation multiplier, >= 0. Default 1; does not change Doppler shifts.

Optional temperature

temperature: number
  • Defined in BlackHole.ts:22

Maximum mean midplane rest-frame temperature in Kelvin. Default 6500.

Optional turbulence

turbulence: number
  • Defined in BlackHole.ts:28

Illustrative turbulent density/emission contrast, from 0 to 1. Default 0.65.
